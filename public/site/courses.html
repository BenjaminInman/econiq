Questions

Before you enroll.

Which tier should I start with?

Recon, unless you already have a phase read you're confident in and want it stress-tested. Recon is the framework; the tiers above it are application and scale. Nobody skips it.

Read or watch?

Recon launches as a read-through with assessments embedded after each chapter. The video version follows, and enrollment includes both when it ships — you won't pay twice.

How new is this framework?

Built late 2025 through mid 2026, out of twenty years of operating and a set of specific, costly mistakes. It did not produce my track record — my track record is what taught me it was missing. Every phase read gets published and dated so you can judge it going forward.

Do I need Cignal System to use this?

No. Recon teaches you to run the read manually, which is how you should learn it. Cignal makes it faster once you know what you're looking at.

Is there a refund policy?

Yes — details on the enrollment page. If the first two modules don't change how you think about your own market, it isn't for you and you shouldn't pay for it.
